The simplest way to run and download MockServer is by using the fully stand alone web server embedded with all dependencies that mocks HTTP and HTTPS requests, as follows:

  1. download mockserver-netty-no-dependencies-{{ site.mockserver_version }}.jar from Maven Central

  2. java -jar <path to mockserver-netty-no-dependencies-{{ site.mockserver_version }}.jar> -serverPort <port>

On Linux, the -jar-with-dependencies-linux-x86_64 and -jar-with-dependencies-linux-aarch_64 jars are about 13 MB smaller than the cross-platform jar, because each keeps only that one Linux architecture's native libraries instead of every supported OS/architecture. They are not tested or supported on macOS or Windows — use the cross-platform jar above there. See Maven Central — mockserver-netty variants.
